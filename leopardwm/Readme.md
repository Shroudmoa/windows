# LeopardWM

A lightweight tiling window manager for Windows.

## Installation

Install LeopardWM using WinGet:

```powershell
winget install jcardama.LeopardWM
```

## Configuration

Config path:

```text
C:\Users\<your-username>\AppData\Roaming\leopardwm\config\config.toml
```
